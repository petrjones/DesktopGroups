# PJSoft Desktop Groups

Launch your everyday applications with one click and restore their saved window layouts.

Desktop Groups is a free Windows utility for people who regularly open the same applications and arrange their windows in the same positions. Organize applications, documents, manuals, shortcuts, and web links into named desktop groups.

Works with one or multiple monitors.

## Download

[Download the latest release](https://github.com/petrjones/DesktopGroups/releases/latest)

Expand **Assets** on the release page and download the **PJSoft-Desktop-Groups-Setup** `.exe` file.

Run the installer to install Desktop Groups or update an existing installation. Saved groups and window layouts are preserved.

## What's new in 1.5.1 — changes since 1.3.0

### More control over application startup

Each group item can now use its own launch behavior:

- Launch immediately.
- Wait for a specified number of seconds before launching.
- Launch and wait until its window appears.
- Wait for the previous application's window before launching.

A configurable timeout prevents an application with no recognizable window from blocking the remaining items.

### Window diagnostics

Item diagnostics help identify applications whose windows are difficult to recognize. They show:

- Process path and process name.
- Window title and window class.
- Monitor.
- Match strength and whether recognition is unambiguous.

Diagnostics display the current state of open windows; they are not saved automatically.

### Built-in help and easier item settings

- Open the offline user guide with **F1** or the **?** button.
- Open item settings using the visible **⚙** button in Edit mode or by double-clicking the tile.
- Access launch-order help directly from item settings.

### About and update checks

The new **About** window provides application information, component licenses, the user guide, and project links.

Check for updates manually or enable an automatic check at most once every 24 hours. Desktop Groups checks the latest stable GitHub release. It does not download or install updates automatically.

### German language

The interface and built-in help are now available in **Czech, English, Spanish, and German**.

## Main features

- Create named, color-coded desktop groups.
- Launch a complete group of applications with one click.
- Save and restore window positions, sizes, monitors, and maximized states.
- Keep separate window layouts for different monitor counts.
- Automatically select the matching layout and offer the nearest saved variant when needed.
- Resize desktop group panels; application tiles reflow automatically.
- Reorder items by dragging their tiles in Edit mode.
- Temporarily hide groups without deleting their settings.
- Safely request that recognized group windows close, allowing applications to prompt for unsaved changes.
- Keep applications and their manuals or reference documents together.
- Export, import, and restore configuration.
- Maintain automatic configuration backups.
- Optionally display groups after signing in to Windows.
- Microsoft PowerToys is not required.

## Quick start

1. Install Desktop Groups.
2. Click **+ Group** and enter a name.
3. Enable **Edit** mode and add applications, documents, shortcuts, or web addresses.
4. Drag tiles to set their launch order. Use **⚙** to configure an item's startup behavior.
5. Open the applications and arrange their windows.
6. Click **Save window layout** and select the windows belonging to the group.
7. Next time, click **Launch all** to start the applications and restore their saved layout.

For manuals and reference documents, disable launching with **Launch all** in the item's settings. They remain available for individual use.

Window layout operations respect the active Windows virtual desktop.

## Requirements and installation

- Windows 10 or Windows 11.
- 64-bit system.
- No administrator privileges required for installation.

The installer updates the existing installation. Configuration is preserved during updates.

To display groups automatically after signing in, select the corresponding installer option. The installer configures the required startup argument.

# PJSoft Skupiny na ploše

Spusť svou každodenní sadu aplikací jedním kliknutím a obnov jejich uložené rozložení oken.

Skupiny na ploše jsou bezplatná aplikace pro Windows určená lidem, kteří pravidelně otevírají stejné programy a rozmisťují jejich okna na stejná místa. Do pojmenovaných skupin lze přidávat aplikace, dokumenty, manuály, zástupce i webové odkazy.

Aplikace funguje na jednom i více monitorech.

## Stažení

[Stáhnout nejnovější vydání](https://github.com/petrjones/DesktopGroups/releases/latest)

Na stránce vydání rozbal **Assets** a stáhni instalační soubor **PJSoft-Desktop-Groups-Setup** s příponou `.exe`.

Instalátor provede novou instalaci nebo aktualizuje stávající. Uložené skupiny a rozložení oken zůstanou zachovány.

## Co je nového ve verzi 1.5.1 — změny od 1.3.0

### Podrobnější řízení spouštění

Každá položka skupiny může mít vlastní způsob spuštění:

- Spustit okamžitě.
- Před spuštěním počkat zadaný počet sekund.
- Spustit a počkat, dokud se neobjeví její okno.
- Před spuštěním počkat na okno předchozí aplikace.

Nastavitelný časový limit zabrání tomu, aby aplikace bez rozpoznatelného okna zablokovala spouštění dalších položek.

### Diagnostika oken

Diagnostika položky usnadňuje řešení potíží s rozpoznáváním aplikací. Zobrazuje:

- Cestu a název procesu.
- Titulek a třídu okna.
- Monitor.
- Sílu shody a informaci, zda bylo okno jednoznačně rozpoznáno.

Diagnostika zobrazuje aktuální stav otevřených oken; automaticky se neukládá.

### Vestavěná nápověda a dostupnější nastavení

- Uživatelskou nápovědu otevřeš klávesou **F1** nebo tlačítkem **?**. Je dostupná i bez internetu.
- Nastavení položky otevřeš viditelným tlačítkem **⚙** v režimu Upravit nebo dvojklikem na dlaždici.
- Z nastavení položky lze otevřít přímo kapitolu o pořadí a čekání při spouštění.

### O aplikaci a kontrola aktualizací

Nové okno **O aplikaci** obsahuje informace o programu, licence součástí, přístup k návodu a odkazy na projekt.

Aktualizaci lze zkontrolovat ručně nebo zapnout automatickou kontrolu nejvýše jednou za 24 hodin. Program ověřuje poslední stabilní vydání na GitHubu. Aktualizace sám nestahuje ani neinstaluje.

### Němčina

Rozhraní i vestavěná nápověda jsou nyní dostupné v **češtině, angličtině, španělštině a němčině**.

## Hlavní funkce

- Pojmenované a barevně odlišené skupiny na ploše.
- Spuštění celé skupiny aplikací jedním kliknutím.
- Uložení a obnovení polohy, velikosti, monitoru a maximalizovaného stavu oken.
- Samostatná rozložení pro různé počty monitorů.
- Automatický výběr odpovídajícího rozložení a nabídka nejbližší uložené varianty.
- Změna šířky a výšky panelů s automatickým přeskupením dlaždic.
- Změna pořadí položek přetažením myší v režimu Upravit.
- Dočasné skrytí skupin bez odstranění jejich nastavení.
- Bezpečné hromadné zavření rozpoznaných oken s možností uložit změny v jednotlivých aplikacích.
- Aplikace a jejich manuály nebo pomocné dokumenty pohromadě.
- Export, import a obnovení konfigurace.
- Automatické zálohy nastavení.
- Volitelné zobrazení skupin po přihlášení do Windows.
- Microsoft PowerToys není potřeba.

## Rychlý začátek

1. Nainstaluj Skupiny na ploše.
2. Klikni na **+ Skupina** a zadej název.
3. Zapni režim **Upravit** a přidej aplikace, dokumenty, zástupce nebo webové adresy.
4. Přetažením dlaždic nastav pořadí spouštění. Tlačítkem **⚙** uprav způsob spuštění jednotlivých položek.
5. Otevři aplikace a rozmísti jejich okna.
6. Klikni na **Uložit rozložení oken** a vyber okna patřící do skupiny.
7. Příště stačí **Spustit vše**. Program otevře aplikace a obnoví jejich uložené rozložení.

U manuálů a pomocných dokumentů lze v nastavení vypnout spouštění tlačítkem **Spustit vše**. Ve skupině zůstanou dostupné pro samostatné otevření.

Operace s rozložením respektují právě aktivní virtuální plochu Windows.
